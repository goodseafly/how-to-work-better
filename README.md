# 高性价比职场指南

教你在签第一份合同之前把公司查清楚，把工资、加班费和没休完的年假一分不少地要回来，把社保断缴、工伤、怀孕生育这些事接上。教你在被针对、被调岗、被裁的时候怎么走，走的时候怎么不留尾巴。也教你看清竞业、保密和职务犯罪的红线在哪，副业能不能干、编制内外差在哪、学什么能回本。法律、社保、公积金这些制度上的内容，按中国大陆的现行规定写。<br>
576 条建议，每条写明花掉什么、换回什么、证据有多硬，来源只引官方文件原文和研究文献。

不用全做：这是按性价比排好的备选单，不是任务清单——挑走一两条就算数。

**这本书只有这一个仓库，没有别的版本。** 从没有授权任何机构以本书名义招生、代报名、推荐岗位或者收费，也没有卖过课程、资料包和会员。看到这类收费的，跟这本书没有关系——那种套路书里第 1 节就写了，见[第 1 节第 9 条（收费培训）](book/01-别进错公司.md)。

## 怎么读

- **看到「别」「不能」开头的节名不用紧张。** 节名说的是这一节帮你防住的事（别进错公司、别把自己送进去），不是说底下每条都在让你别干什么。真正要做的动作写在条目标题里，一律动词开头，自己就写清了是「做什么」还是「别做什么」。
- **按性价比读。** 每节内的条目不是按时间排的，也不是按流程排的，是按「花出去多少、换回来多少」排的。最前面那几条通常不花钱、不费时间，先做这些。
- **按成本标签筛。** 每条标题下面有一行只有机器看得见的成本标签，把「钱」「时间」「毅力」三样标出来。你只想找不花钱的，就筛「钱=0」。
- **按口径分开看。** 每条说的是换回什么——钱、时间、健康、岗位还是人身自由。不同口径之间不做比较：一条省下两万块的条目，和一条避免刑事责任的条目，谁更值不值得做，没有统一答案。
- **只想看结论最硬的。** 在[在线检索页](https://goodseafly.github.io/how-to-work-better/)里勾选证据等级 A，只留下引到法律、行政法规、部委规章和官方统计原文的 518 条。
- **只想看最值得做的。** 勾选性价比「极高」，得到 133 条既不花钱、不花时间、不需要毅力，收益又落在最大一档的条目。再叠加一个「换回什么」，就是该口径下的优先清单。
- **想按条件挑。** 打开[在线检索页](https://goodseafly.github.io/how-to-work-better/)（想用本地那份也行，见下文「自己跑一份」），可以按关键词、章节、证据等级来筛，也可以按「花不花钱、花多少时间、要不要毅力」三样筛，几个条件能叠着用。页面上的内容直接取自 book/ 目录里的正文，正文一改，重跑构建脚本页面就跟着改。
- **想离线看、想发给别人。** 离线单文件版（高性价比职场指南-全本.html）整本书连同检索和筛选都在一个文件里，双击就开，不用服务器也不用联网，微信里也能直接传。
- **想打印或在手机上翻。** 用 PDF 版：A4 排版、五百多页，带目录页码和书签，每节另起一页。
- **想在 Kindle 或其他阅读器上读。** 用 EPUB 版（高性价比职场指南.epub），Kindle 用 Send to Kindle 发过去即可。
- **长文另见 docs/**：[被裁之后三十天](docs/被裁之后三十天.md)、[劳动仲裁怎么走](docs/劳动仲裁怎么走.md)、[入职前先查什么](docs/入职前先查什么.md)。长文把散在各节的条目按时间先后串成行动清单，每一步都注明出自第几节第几条，不引入正文以外的新数字。
- **条目之间会互相指路**（「见第 8 节第 17 条」这种）：检索页里这种指路带一条虚线，点一下就地显示被指那条的标题和「说人话」。在 GitHub 或纯文本里读，括号里写着指向什么，不翻过去也知道说的是哪条。
- **看法条看原文。** 每条「来源」栏给的是原文出处，法条带条款号。看「说人话」那一栏能知道大概意思，要拿去用就翻原文。

## 每条建议长这样

下面是书里真实的一条（第 26 节第 2 条），六栏都在：

```markdown

### 2. 让公司出书面解除通知，把解除依据写进去

<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=大 口径=岗位 -->

- 成本：不花钱，要的是开口要一份文件。难在 HR 常常口头通知，你走了以后程序上什么都没有。
- 说人话：解除或者终止劳动合同时，公司要出具书面证明。公司只口头说一句让你走，你照常上班、照常打卡，别自己先撤。哪天解除、按哪一条解除，都要落到纸上。
- 收益：解除或者终止你的合同，公司要出具书面证明，还要在十五日内为你办完档案和社会保险关系转移。这份证明上要写明合同期限、解除或者终止的日期、工作岗位、在本单位的工作年限。无过失性辞退的，还要提前三十日书面通知，或者多给一个月工资。真打起来，举证责任在公司——它得证明自己说过什么、依据是什么。（依据：劳动合同法第四十、五十条；劳动合同法实施条例第二十四条；最高人民法院劳动争议解释（一）第四十四条）
- 证据等级：A
- 来源：全国人大常委会 (2012). 劳动合同法（第四十、五十条）. <http://www.gov.cn/gongbao/content/2007/content_711013.htm>；国务院 (2008). 劳动合同法实施条例（国务院令第 535 号，第二十四条）. <https://www.gov.cn/zhengce/content/2008-09/19/content_6630.htm>；最高人民法院 (2020). 关于审理劳动争议案件适用法律问题的解释（一）（法释〔2020〕26 号，第四十四条）. <https://www.court.gov.cn/fabu/xiangqing/282121.html>
- 备注：证明里写「解除」还是写「你自己辞职」，会牵动经济补偿和失业金，见第 7 节第 14 条（并给你出解除证明）。公司不出证明的，找劳动行政部门责令改正，见第 12 节第 14 条（结清工资和社保转移）。通知、邮件、聊天记录怎么留，见第 12 节第 4 条（开始留证）。

```

## 这本书想帮你换回什么

这本书想帮你留住五样东西：

- **钱**：该拿的工资、加班费、经济补偿和补贴，一分不少地要回来
- **时间**：年休假、病假、医疗期和离职那几天的缓冲，一天不白搭
- **健康**：在被工作搞垮之前先止损，伤了病了知道该找谁、钱由谁出
- **岗位**：这份工作保不保得住，什么时候该走、走的时候能拿什么
- **自由**：不因为不知道一条红线，把自己送进拘留所或者看守所

每条建议都回答两个问题：要花掉什么（钱、时间、毅力），能换回什么（上面五样里的哪一样）。条目按性价比排，不按流程排：几乎不花成本、换回的好处又大的，放在最前面。

**这五样之间不互相折算。** 一条省下两万块的条目，和一条避免刑事责任的条目，谁更值得做，没有统一答案。这也是「口径」那一栏的意思：它说的是换回来的是哪一类东西，不是给不同类别排座次。

## 三样成本

写条目时先算花出去什么。三样都不花的条目，一般也没用。

| 成本 | 怎么看 |
| --- | --- |
| 钱 | 不花钱、或者反过来省钱，记 0；几十到几百元、或者每月几十元以内，记「少」；上千元或者长期显著支出，记「多」 |
| 时间 | 一次几分钟内、顺手就做的，记「少」；一次性数小时、或者每周小时级，记「中」；每天持续占用的，记「多」 |
| 毅力 | 做一次就完的，记「否」；要改一个习惯、或者忍一点不适的，记「些」；要长期对抗惯性的，记「是」 |

## 五种口径

收益按这条主要换回什么定。**不同口径之间不做比较。**

| 口径 | 说的是什么 | 大 | 中 | 小 |
| --- | --- | --- | --- | --- |
| 金钱 | 直接进出的钱 | 万元级 | 数百到数千 | 几十元 |
| 时间 | 省下来的时间 | 每天省出小时级 | 每周小时级 | 只省一次 |
| 健康 | 身体和心理的状况 | 相对风险降 20% 以上 | 降 10% 到 20% | 降不到 10%，或者只量到中间指标 |
| 岗位 | 这份工作保不保得住 | 保住工作的关键动作 | 明显降低被边缘化的概率 | 只影响观感 |
| 自由 | 人身自由，以及会不会被拘留、被判刑 | 避免刑事责任，或者避免被限制人身自由 | 避免拘留或行政处罚 | 避免民事纠纷 |

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 官方文件原文，包括三类：① 中国法律、行政法规、司法解释、部委规章与规范性文件的条文原文；② 官方统计，比如国家统计局、人社部发布的数字，且已核实原文；③ 权威国际组织的正式出版物，比如世界卫生组织、国际癌症研究机构的官方文件、专论和 fact sheet。法律和政策类条目引到原文即可，不需要数字 |
| B | 包括四类：① 单篇同行评议研究、系统综述与汇总分析，含 Cochrane 系统综述；② 学会或专业组织的共识报告；③ 有官方文件但关键数字由地方确定，本书核不到统一值的；④ 只有单一来源支撑的结论 |
| C | 作者经验 |

- **书里引用的世卫组织、国际癌症研究机构文件按「官方文件原文」计 A 级，与国内法条同级；单篇研究和综述计 B 级。**
- **证据等级说的是「收益」栏里的法条和数字有多硬，不是说这条建议本身有多对。**一条建议可以证据是 A 级（引的法条确实这么写），而「要不要照做」仍然是你自己的判断——这种情形会在备注里写明。
- **A 级不等于你会赢。** 对法律类条目，A 级只说明这条法条确实这么写、出处可核。各地裁审口径有差异的，写进备注。
- 有争议的条目会在备注开头标「争议」，并把反方依据列出来。
- **取证说明**：国家法律法规数据库（flk.npc.gov.cn）已改为前端单页应用，详情页地址无法稳定复现，但该库挂在 `wb.flk.npc.gov.cn/flfg/PDF/` 下的 PDF 直链可以正常访问，正文里用到这类直链的地方（第 4、5 节的劳动法）都用脚本逐条抽过原文比对。有几份法规拿到的官方 PDF 是扫描件、没有文字层（关于工资总额组成的规定、劳动争议调解仲裁法的数据库版本），改用地方人社局网站的可检索副本，两处逐字互证后才定稿。最高人民法院公报站点先下发 cookie 再重定向到同一地址，核验链接时要带 cookie 会话，否则正常链接会被误判成死链。除此之外的法律全文引中国政府网、部委官网或地方政府的全文页面，全部逐条核过可访问。是否与权威数据库文本一致，转载前建议再对一遍。

## 性价比档

| 档 | 怎么定 |
| --- | --- |
| 极高 | 好处大，三项成本全是零 |
| 高 | 好处大、成本不高，或者好处中等、成本为零 |
| 一般 | 剩下的 |

全书 576 条中性价比极高 133 条（23%）、高 267 条（46%）、一般 176 条（31%）。中间那档条数多是有意的：底下的收益量级本来就只分大、中、小三级，再往细里切就是装出来的精确。

性价比是作者自己的判断，按本书的标准它本身只算 C 级，和证据等级是两回事。「一般」不等于不该做——全书的条目都是建议做的，只是这一档得你自己掂量那笔花销值不值。

| 非因本人意愿中断就业 | 领失业金的条件之一。包括合同期满终止、被单位解除、被开除除名辞退等。自己主动辞职一般不算 |

| offer | 录用通知书。法律上一般算订立合同的要约，单位发出来又撤回的，可能构成缔约过失，要赔你因为信赖它而产生的损失 |

## 章节之间怎么分工

有几处两节内容相邻，容易搞混该翻哪一节，这里先说清：

- **失业保险金**的领取条件、期限、标准和领钱期间医保由谁缴，在**第 7 节**。失业之后的整体安排——申领流程、失业登记、公积金、年金、灵活就业参保——在**第 28 节**。
- **工伤认定的一般规则**在**第 8 节**。办公场所突发急症和 48 小时起算，在**第 32 节**。
- **解除劳动关系的实体权利**（能不能解除、拿多少补偿）在第 **25、26 节**。维权的程序——投诉、仲裁、诉讼、强制执行——统一在**第 27 节**。
- **竞业限制的完整制度**在第 **17 节**。跳槽时怎么判断竞业协议会不会生效，在第 **24 节**。
