# 传播物料包

这一包是给想推荐这本书的人准备的：**下载即用，不用自己做图**。

- `cards/` — 12 张卡（1080×1350，4:5，小红书／朋友圈竖图尺寸）：7 张场景卡 + 5 张算账卡
- `scripts/口播稿.md` — 3 条 30–60 秒口播稿，可直接念
- `cards.html` — 卡片源文件，改完用无头浏览器重新截图即可

每张卡都标了出自第几节第几条，文案全部取自 `book/` 正文，没有书外的新数字。数字过时了以书为准，书过时了以官方原文为准。

## 用这些卡的三条规矩

1. **别加二维码、微信号和站外链接。** 平台（尤其小红书、抖音）把站外导流列为封号级红线，原卡上就没有，加上去等于替这本书踩雷。让人搜书名就够了。
2. **别下个案结论。** 有人问「我这个情况能拿多少」，标准回复是：规定是这么写的，具体到你的情况要问当地仲裁委或律师。书里也是这么写的（分流，不处置）。
3. **注明出处即可，不用来问作者。** CC BY 4.0 允许转载、改编和商用。
